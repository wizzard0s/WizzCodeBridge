# Research skill

- Inspect the target workspace and its existing guidance before proposing changes.
- Separate observed facts, external claims, assumptions, and unanswered questions.
- Prefer primary sources; include source URLs and access dates for web findings.
- Do not claim to have browsed when the configured web research tool is unavailable.
- Return concise findings that the requirements analyst and architect can use.

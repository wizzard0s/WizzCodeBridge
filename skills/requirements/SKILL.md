# Requirements skill

- Ask a thorough first batch of relevant questions before planning.
- Ask follow-up questions when answers expose consequential gaps or conflicts.
- When the user is unsure, explain practical choices and research what configured tools allow.
- Mark assumptions and unresolved decisions explicitly; never silently decide high-impact behavior.
- Convert agreed needs into acceptance criteria that can be checked.
